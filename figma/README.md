# 피그마로 옮기기

## 들어 있는 것
- `screens.html` — 앱의 모든 화면(25개)을 휴대폰 크기(390×844)로 펼쳐 놓은 정지 화면. 피그마 플러그인으로 불러오는 용도
- `icons/` — 아이콘 SVG 23개 (로고, 종, 알림 끔, 번개, 메뉴 아이콘 등). 피그마에 끌어다 놓으면 벡터로 편집 가능
- 앱 자체는 `../index.html` (눌러 볼 수 있는 프로토타입)

## 순서
1. 깃허브 메인에 올리기 (Claude에게 "깃허브 메인에 올려줘")
2. GitHub Pages 켜기: 저장소 → Settings → Pages → Branch를 `main` / `/(root)`로 → Save
3. 주소 확인: https://theblueyoung.github.io/24dday/figma/screens.html
4. Pretendard 글꼴 설치: https://github.com/orioncactus/pretendard/releases (최신 버전 zip → 압축 풀고 글꼴 설치)
5. 피그마 → 플러그인 html.to.design 설치 → 3번 주소 붙여넣고 Import
6. icons 폴더의 SVG를 피그마에 끌어다 놓기
